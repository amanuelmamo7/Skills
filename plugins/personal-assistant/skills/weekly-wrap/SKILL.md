# Weekly Wrap

Read a week's worth of daily logs and synthesize — not a re-listing of each day, but the themes, patterns, and honest misses that only show up at week scale.

## How to use

1. Read all of the week's daily logs (morning briefs, evening wraps, and any daily notes — `memory/YYYY-MM-DD*.md` in the original layout).
2. Synthesize into:
   - **Themes** — what actually dominated the week, vs. what was planned to.
   - **Patterns** — recurring frictions, repeated punts, meetings that keep spawning follow-ups.
   - **Time allocation** — a rough split of where the week went.
   - **Course corrections** — two or three specific changes for next week.
   - **What got punted** — the honest list, carried forward explicitly.
3. Write to a week-stamped file (`memory/YYYY-Www-wrap.md` in the original, ISO week number).

Related skills: `morning-brief`, `evening-wrap` (produce the inputs), `memory-maintenance` (the Sunday distillation pass).
