# Pointed Analysis

The lightweight format for one-off analytical questions: direct answer first, then the work, then the falsifiers. No throat-clearing.

## How to use

1. Read `references/analysis-rules.md` — comp set named, numbers carry units and as-of dates, decomposition where applicable, conviction calibrated, no recommendations.
2. Restate the question in one sentence. If it's ambiguous, name the ambiguity, pick the most defensible interpretation, and flag whether the other interpretation would change the answer.
3. Give the one-line answer immediately, conviction-calibrated.
4. Fill the rest of `assets/pointed-analysis-template.md`: prior → fetch log table (source, URL, timestamp, used-for) → free-form analysis under the house rules → the Observed/Implied/Actual/Gap block if it's an is-the-move-justified question → what I don't know (explicit, with what would close the gap) → what would change my mind → sources.

## Bundled resources

- `assets/pointed-analysis-template.md` — the exact output template.
- `references/analysis-rules.md` — house analysis rules.

Related skills: escalate to `trend-justification`, `company-thesis`, or `stock-deep-dive` when the question deserves the full treatment.
