- not pre-revenue biotech

----- AUTO-CHECK FOR PRE-REVENUE BIOTECH FILTER -----

Before excluding a name on the biotech filter, run an automated TTM revenue
check via Yahoo Finance (https://finance.yahoo.com/quote/<TICKER>/key-statistics)
and pull the "Revenue (ttm)" field. If TTM revenue ≥ $10M, do NOT exclude
the name regardless of clinical/biotech classification. This closes the ABVX
edge case (large biotech with EU commercial revenue passed by the previous
exclusion).

If Yahoo Finance is blocked, fall back to StockAnalysis "key-statistics" or
SEC EDGAR XBRL revenue lookup. Log which source you used in the tracking
file's verification block per name.

----- CATALYST VERIFICATION CHAIN (tiered, fail-forward) -----

Tier 1: Direct primary source. Fetch PR Newswire (prnewswire.com), Business
Wire (businesswire.com), GlobeNewswire (globenewswire.com), or EDGAR 8-K.
Pass: tag verification_tier: 1. Fail (404, blocked, or no result): proceed to T2.

Tier 2: Google News headline aggregation. Query Google News with:
   "<TICKER>" OR "<Full Company Name>"
with 7-day date filter. Apply this rubric (sum must reach ≥70%):
   +50%: headline contains company name + positive verb cluster
         (announces, unveils, launches, signs, partners, awarded,
         approves, completes, expands, acquires)
   +20%: multiple independent publishers (≥2) report same event
   +20%: headline theme/sector matches the spike's narrative cluster
Pass ≥70%: tag verification_tier: 2 and the confidence score (50-100%).
Below 70% or if Google News is blocked: proceed to T3.

Tier 3: archive.ph fallback for substance. When a headline confirms catalyst-
present but Sefer needs the substance (named partners, dollar values), query
archive.ph for the headline-promising URL. Pass: tag verification_tier: 3.
Fail: proceed to T4.

Tier 4: EDGAR EFTS direct ticker search. Query:
   https://efts.sec.gov/LATEST/search-index?q=<ticker>&dateRange=custom&...
for any same-day or within-7-day 8-K filing. Pass: tag verification_tier: 4.
Fail: catalyst not verified. Per the gate rule, this excludes the name from
Section 2 (exceptional gate). For Section 1 (primary) names, "no catalyst
found" is itself a finding — produce the analysis but verdict-tag as
"unclear/sector-beta" and tier the name C.
