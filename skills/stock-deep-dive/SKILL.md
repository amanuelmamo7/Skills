# Stock Move Deep-Dive

The heaviest single-name analysis format: decompose a violent move, judge whether it's justified, and leave the reader knowing exactly what to watch next. Modeled on a reference STI analysis — match its structure and rigor.

## How to use

1. Read `references/analysis-rules.md`. The rules are load-bearing here: prior before evidence, mechanical decomposition, named comp set, cyclical vs. secular, falsifiers, and **no buy/sell recommendations** — the verdict is analytical ("this pattern historically retraces 50–80% within 2–4 weeks without a named partner"), never advice.
2. Fetch primary sources for the catalyst: the actual PR, 8-K, or filing. Quote the headline; note what the release does *not* contain (no signed contract, no named partner, no guidance).
3. Fill `assets/deep-dive-template.md` section by section — all twelve: prior → catalyst → return decomposition table (sums to ~100%) → mechanism → three scenarios with probabilities → framework test (Observed/Implied/Actual/Gap/Verdict/Conviction) → comparison set (historical analogs with ticker + date + outcome, and current peers with multiples) → institutional angle (institutional vs. hedge fund vs. retail vs. options gamma flow) → what would change my mind (three falsifiers) → watch list (7/30/90 days) → bottom line → sources with verification-tier status.
4. Target 1000–1500 words unless the data doesn't support the depth — if so, say why explicitly rather than truncating silently.

## Bundled resources
