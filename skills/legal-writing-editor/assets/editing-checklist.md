# Legal Editing Checklist — run all four passes, in order

Draft: <file / section> · Date: <date> · Editor output: edited draft + change report (edits made / flags for author)

## Pass 1 — Architecture (repeat per legal argument)

- [ ] Explanation of law precedes and is separate from application
- [ ] Everything explained is applied (unused explanation → cut or flag)
- [ ] Everything applied was explained (unexplained reliance → FLAG)
- [ ] Case illustrations contain every fact their analogies later use — and no more
- [ ] Conclusion stated up front and restated after the analysis
- [ ] Counter-analysis present where contestable (absent → FLAG, do not write)

## Pass 2 — Flow

- [ ] Roadmap opens multi-issue discussion; mini-roadmaps for multi-part arguments
- [ ] Headings state points, not topics
- [ ] Every paragraph opens with a one-point topic sentence; contents serve it
- [ ] Transitions carry the logic between arguments

## Pass 3 — Sentences

- [ ] One idea per sentence
- [ ] Subject near verb; actor as subject
- [ ] Passive voice only where the actor is unknown or irrelevant
- [ ] Nominalizations converted to verbs
- [ ] One term per concept throughout (no elegant variation)

## Pass 4 — Mechanics

- [ ] Spelling, grammar, names, dates
- [ ] Numbers checked against their stated provenance
- [ ] Citations present, formatted, pincited; quotes verbatim or `[quote unverified]`
- [ ] Defined terms used as defined; cross-references resolve
